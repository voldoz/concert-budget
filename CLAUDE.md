# Concert budget app

- The whole app is `index.html` (vanilla JS + Supabase project `awkkcmyeaovcuiphlzye`), served by GitHub Pages from `main`.
- On every release, bump `APP_VERSION` and write a short Arabic `APP_NOTES` (no apostrophes) near the top of the script. Open copies of the app poll the published file and show an update banner when the version changes.
- UI text is Arabic, RTL.
